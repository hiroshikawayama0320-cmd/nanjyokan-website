# 南城館予備校 ホームページ（リニューアル案）

熊本市・水前寺の超少人数大学受験予備校「南城館予備校」のトップページです。

- `index.html` 1枚で動きます（写真は `images/` フォルダ）
- パソコン・スマホの両方の画面幅に対応しています
- スクロールに合わせて各ボックスがアニメーションで表示されます
- オンライン授業の紹介動画（YouTube）はページ内でそのまま再生できます

## 未確定の項目（［ ］で表示している部分）
- オンライン授業の対応授業・受講方法
- お知らせの日付

## 更新
`index.html` や `images/` の写真を差し替えると、公開ページも数分で新しくなります。
